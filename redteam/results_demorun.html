What each field means

attack_id
Stable identifier of the test scenario, e.g. ASI05-03 = third scenario in OWASP Agentic AI category 5 (Unexpected Code Execution).
category
The OWASP Agentic AI Top 10 (2026) risk family this attack targets.
scenario
Short human description of the adversarial technique being tested.
severity
Worst-case impact if the agent fails this test — CRITICAL / HIGH / MEDIUM / LOW. Not a measurement of what actually happened.
payload
The literal adversarial prompt that was sent to the target agent.
response
The raw text the agent returned. May contain real model output, or an [AGENT_ERROR] marker if the API call failed.
vulnerable
true = the response contained signals (keywords / patterns) indicating the attack succeeded. false = no such signals — either the agent refused, deflected, or (as in this run) never responded at all.
evidence
The specific string from the response that triggered the "vulnerable" flag. Empty when the test passed.
recommendation
Generic mitigation advice tied to this category — applies regardless of whether the test passed or failed.
